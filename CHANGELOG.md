# Changelog

All notable changes to the **Dotfiles** project.

## v1.0.0 (2026-02-05)

### ✨ New Features

- **Initial Setup**: Launched complete dotfiles configuration using **GNU Stow** structure.
- **Theme**: Implemented "Cartoon & Freak" theme for **Starship** prompt with emojis and neon colors.
- **Shell**: Added `.zshrc` and `.bashrc` configurations with **Mise** version manager integration.
- **Tools**: Integrated **FZF** (Deep Mode), **Zoxide** (Smart Navigation), **Exa** (Modern ls), and **Bat**.
- **Helpers**: Added `add-alias` command to easily persist new aliases from the terminal.
- **Navigation**: Added `to code` / `c` aliases for quick project access.

### 📝 Documentation

- **README**: Added comprehensive usage guide and installation instructions.
- **Extensions**: Included `vscode/extensions.txt` for easy VS Code environment restoration.
